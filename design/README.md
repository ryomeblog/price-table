# 底値表アプリ 画面設計書

## 概要
底値表アプリは、各スーパーマーケットでの商品価格を比較・記録し、最安値で購入できるように支援するWebアプリケーションです。

## 画面構成

### 1. 底値表一覧画面 (`price-table-list.svg`)

#### 主要機能
- **商品検索**: ヘッダー部分の検索バーで商品名による絞り込み
- **商品アコーディオン**: 商品名ごとにグループ化、展開/折りたたみ可能
- **価格比較テーブル**: 各商品の価格情報を一覧表示
- **新規追加**: 右上の「新規追加」ボタンでモーダル画面を開く

#### UI要素
- **ヘッダー**: アプリタイトル、新規追加ボタン
- **検索バー**: プレースホルダー「商品名で検索...」
- **アコーディオンリスト**: 
  - 展開状態: 詳細テーブル表示
  - 折りたたみ状態: 商品名のみ表示
- **データテーブル**: 値段、単位、数量、単価、場所、備考、操作ボタン
- **最安値表示**: 最も安い商品には「最安値」バッジを表示

#### カラー設計
- プライマリカラー: #3b82f6 (青)
- アクセントカラー: #10b981 (緑) - 新規追加、最安値表示
- 危険色: #ef4444 (赤) - 削除ボタン
- 背景色: #f8fafc (淡いグレー)

### 2. 買い物リスト画面 (`shopping-list-index.svg`)

買い物リスト（グループ）と、その中の商品アイテムを **入れ子アコーディオン** で表示する画面。
底値表画面とはヘッダーのトグルボタンで切り替える。
商品詳細表示はこの画面の内側アコーディオンで完結する（旧仕様にあった独立の「商品詳細画面」は廃止）。

#### 主要機能
- **外側アコーディオン**: 買い物リスト（グループ）。左端チェック → モーダル確認 → リスト物理削除
- **内側アコーディオン**: そのリストに属する商品アイテム
  - 左端チェック → **グレーアウト + 一番下に移動**（物理削除しない、確認不要）
  - チェックを外せば未チェック群の末尾に戻る（撤回可能）
  - 商品をさらに展開すると底値表と同じ価格テーブルを表示
- **編集ボタン**: 右端の「編集」で `ShoppingListForm` へ
- **件数バッジ**: 「N件 (買済 M)」形式で進捗を可視化
- **ビュー切替**: ヘッダーの「底値表」ボタンで底値表画面に戻る

#### UI要素
- **ヘッダー**: 「買い物リスト」タイトル、ビュー切替ボタン（"底値表"）、「+ 新規リスト」ボタン
- **外側アコーディオンヘッダー**:
  - 左端: 削除トリガのチェックボックス（赤系のフォーカスリング）
  - 中央: 「📝 リスト名」+ 件数バッジ + 展開アイコン（クリックで開閉）
  - 右端: 「編集」ボタン
- **アコーディオン内側 (展開時)**:
  - 上段: リストメモ・作成/更新日
  - 下段: 商品行（`ProductAccordion` を `showCheckbox` + `readOnly` モードで利用）
  - 並び順: 未チェック群（上）→ チェック済み群（下、グレーアウト + 取り消し線）
- **空状態**: 「最初の買い物リストを作成しましょう」と CTA ボタン

#### 削除確認モーダル
外側アコーディオンの左端チェックを ON にすると表示される `Modal` (`size="sm"`)。
「キャンセル」と赤色の「削除する」ボタンを持ち、確定で `deleteShoppingList(id)` を実行する。

### 3. 買い物リスト追加・編集画面 (`shopping-list-form.svg`)

買い物リストの新規作成および編集を行う画面。底値表ビューを再利用し、左にチェックボックスを設けて商品を選択する。

#### 主要機能
- **リスト名入力**（必須・1〜50文字）
- **メモ入力**（任意・最大200文字）
- **商品選択**: 底値表と同じ商品アコーディオンを表示し、左端のチェックボックスで選択／解除
- **アコーディオン展開**: 選択画面でも商品の価格情報を確認可能（編集ボタンは非表示）
- **検索フィルタ**: 既存の SearchBar をそのまま再利用
- **保存／キャンセル**: Ctrl+Enter で保存

#### UI要素
- **ヘッダー**: 「< キャンセル」、画面タイトル、「保存」ボタン
- **リスト情報フォーム**: リスト名（必須）、メモ
- **検索バー**: 既存の SearchBar コンポーネント
- **商品ピッカー**: ProductAccordion を `selectable=true` / `readOnly=true` モードで表示
- **選択数表示**: 「N 件選択中」ラベル

### 4. 底値表入力画面 (`price-table-input-modal.svg`)

#### 主要機能
- **商品情報入力**: 商品名、価格、単位、数量、購入場所、備考
- **単価自動計算**: 価格÷数量で単価を自動算出
- **店舗選択**: よく使う店舗のドロップダウンリスト
- **入力検証**: 必須項目のチェック、数値形式の検証

#### フォーム項目
1. **商品名** (必須): テキスト入力
2. **価格** (必須): 数値入力 + 円表示
3. **単位** (必須): テキスト入力（例：kg, ml, 個）
4. **数量** (必須): 数値入力
5. **単価**: 自動計算（価格÷数量）
6. **購入場所** (必須): テキスト入力 + ドロップダウン選択
7. **備考**: 複数行テキスト入力

#### UX配慮
- **バリデーション**: リアルタイム入力検証
- **キーボードショートカット**: Ctrl+Enter（登録）、Esc（キャンセル）
- **価格履歴**: 同じ商品の過去の価格履歴表示（展開可能）
- **よく使う店舗**: ドロップダウンで効率的な入力

## 技術仕様

### レスポンシブ対応
- デスクトップ: 1200px幅を基準
- タブレット: 768px以下で調整
- モバイル: 480px以下でスタック表示

### アクセシビリティ
- コントラスト比: WCAG 2.1 AA準拠
- キーボードナビゲーション対応
- スクリーンリーダー対応

### データ構造
```javascript
{
  id: string,
  productName: string,
  price: number,
  unit: string,
  quantity: number,
  unitPrice: number, // 自動計算
  store: string,
  notes: string,
  createdAt: Date,
  updatedAt: Date
}
```

## 実装時の注意点

1. **パフォーマンス**: 大量データ対応のため仮想スクロール検討
2. **データ永続化**: LocalStorage or IndexedDB使用
3. **検索機能**: 部分一致、ひらがな/カタカナ対応
4. **ソート機能**: 単価順、更新日順などのソートオプション
5. **エクスポート機能**: CSV/PDF出力機能の追加検討

## 画面遷移

```
┌────────────────────────────────────────────────────────────┐
│  ヘッダー: [リスト ⇄ 底値表] トグル / +新規追加 / I/O / クリア │
└────────────────────────────────────────────────────────────┘
       │
       ├── view='priceTable'   → 底値表一覧画面
       │       └─ モーダル: 商品追加 / 価格追加・編集
       │
       └── view='shoppingList' → 買い物リスト機能
               ├─ subView='index'  → 買い物リスト画面（入れ子アコーディオン）
               │       └─ モーダル: リスト削除確認
               └─ subView='form'   → 追加・編集画面
```

view / subView は React state で管理し、URL ルーティングは導入しない（state ベース）。
詳細仕様は `doc/買い物リスト機能設計.md` を参照。
